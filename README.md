# Smart Plant Doctor 🌿

An AI-powered plant disease detection system designed to identify tea leaf diseases using computer vision and deep learning.

## Overview

Smart Plant Doctor analyzes tea leaf images and predicts possible diseases using a trained deep learning model.

The project aims to support early identification of common tea leaf diseases through image-based classification.

## Features

- Tea leaf image classification
- Detection of six tea leaf categories
- Deep learning-based prediction
- Image processing and computer vision
- Interactive Gradio interface

## Disease Categories

1. Algal Leaf
2. Anthracnose
3. Bird Eye Spot
4. Brown Blight
5. Healthy Tea Leaf
6. Red Leaf Spot

## Technology Stack

- Python
- PyTorch
- TorchVision
- Ultralytics (YOLO / SAM)
- OpenCV
- NumPy
- Pandas
- Scikit-learn
- Gradio
- Pillow

## Disclaimer

This project is developed for educational and experimental purposes. Predictions should not be treated as a definitive agricultural diagnosis.
